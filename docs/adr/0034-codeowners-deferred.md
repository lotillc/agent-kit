# ADR-0034 — CODEOWNERS (deferred)

- Status: Accepted
- Date: 2026-04-20

## Context

Explicit CODEOWNERS adds review friction without adding safety at this stage.

## Decision

Deferred. Revisit once the team grows or access patterns make it material.

## Consequences

No bureaucracy yet. Easy to add later; hard to unwind if added prematurely.
