# Architecture Decision Records

Each ADR captures the **context**, **decision**, and **consequences** of one non-trivial architectural choice. ADRs are append-only — when a decision is superseded, add a new ADR that links back to the one it replaces.

Format is intentionally short: every ADR should read in under 60 seconds.
